# Contributing

Thanks for helping. Bugs and ideas are welcome as issues.

1. Fork the repository and make a branch.
2. Keep it beginner friendly: plain words, nothing to type, no new accounts or keys.
3. Run the checks: `python3 -m unittest discover -s tests`
4. Open a pull request and say what changed and how you tested it.

New picture sources must be free, need no key, and state a licence the kit can check. Never add videos or photos of people without permission.
Be kind: the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) applies here.
